# Капри — голосовой ассистент для Windows

Капри — голосовой ассистент в стиле киберпанка. Она живёт поверх окон, появляется с глитч-вспышками,
слушает команды на русском языке и умеет болтать.

**Что умеет:**
- открывает сайты, программы, папки и сразу включает видео на YouTube по запросу;
- управляет музыкой и видео: пауза, следующий трек, перемотка, «поставь на 3:14»;
- печатает текст и выполняет цепочки: «открой телеграм, чат папа, напиши привет»;
- листает страницы, закрывает вкладки, нажимает клавиши и сочетания;
- закрывает программы и завершает процессы, говорит, что грузит компьютер;
- создаёт файлы и папки, ищет картинки и информацию, управляет громкостью и яркостью;
- проверяет компьютер на ошибки;
- разговаривает с помощью бесплатной локальной нейросети, а без неё работает только на командах.

Полный список команд — в [КОМАНДЫ.md](КОМАНДЫ.md).

---

## Что нужно

- Windows 10 или 11
- Микрофон
- Интернет — для установки, голоса Капри и поиска. Распознавание речи работает и без интернета.
- Для разговоров (необязательно): видеокарта с 8 ГБ памяти или 16+ ГБ оперативной памяти и ~6 ГБ места на диске

## Установка

### Шаг 1. Установи Python

1. Скачай Python 3.11 или новее: https://www.python.org/downloads/
2. При установке **обязательно поставь галочку «Add python.exe to PATH»**.
3. Проверь: открой «Командную строку» и введи `python --version` — должна появиться версия.

### Шаг 2. Скачай Капри

- На странице репозитория нажми зелёную кнопку **Code → Download ZIP** (или скачай архив `capri.zip`,
  если получил его, например, в Telegram).
- Распакуй архив в удобную папку, например `Документы\capri`. Запускать прямо из архива нельзя — сначала распакуй.

> Лучше, чтобы в пути к папке не было русских букв — так надёжнее работает распознавание речи.
> Если всё же есть, Капри сама скопирует модель речи в подходящее место.

### Шаг 3. Запусти установку

Дважды кликни по **`setup.bat`**. Он:
- установит нужные библиотеки Python;
- скачает офлайн-модель распознавания русской речи (~45 МБ).

Дождись надписи «Готово». Установка занимает несколько минут.

> Если Windows покажет «Windows защитила ваш компьютер» — нажми **«Подробнее» → «Выполнить в любом случае»**.
> Так Windows реагирует на любые .bat-файлы из интернета.

### Шаг 4. Запусти Капри

Дважды кликни по **`run.bat`**.

Капри появится на экране и поздоровается, а в трее (у часов) появится её иконка.
Скажи **«Капри, открой ютуб»** — проверь, что всё работает.

> Если Windows спросит разрешение на доступ к микрофону — разреши.
> Проверить можно в «Параметры → Конфиденциальность → Микрофон».

## Команды без нейросети — Капри работает и без ИИ

**Все команды работают сразу после установки**, без нейросети, ключей и регистрации:
сайты, программы, папки, YouTube, поиск, громкость, яркость, клавиши, вкладки, файлы,
диагностика ПК, время, прогулки по экрану и т. д.

Без нейросети на обычные вопросы и болтовню («как дела?», «что такое чёрная дыра?») Капри
просто откроет поиск в Google. Чтобы она **разговаривала сама** — включи нейросеть (следующий раздел).

## Как научить Капри разговаривать (нейросеть, бесплатно, без интернета)

Капри общается через **Ollama** — бесплатную программу, которая запускает нейросеть прямо на компьютере.
Никаких ключей, подписок и отправки разговоров в интернет.

1. Скачай и установи Ollama: https://ollama.com/download
2. Открой «Командную строку» и скачай модель (~5 ГБ):
   ```
   ollama pull qwen3:8b
   ```
3. Перезапусти Капри (меню в трее → «Выход», затем снова `run.bat`).

Готово — теперь на вопросы и болтовню отвечает сама Капри.
Пока она отвечает на вопрос, она скачет по экрану красной молнией.

**Если компьютер слабый** (нет видеокарты или мало памяти), возьми модель полегче и укажи её в
`config.json` → `"local_model"`:
```
ollama pull qwen3:4b
```

**Свежие данные** (погода, новости, курсы, цены) нейросеть не знает — на такие вопросы Капри откроет поиск.

> Ollama после установки сама запускается вместе с Windows (иконка ламы в трее). Не закрывай её —
> иначе Капри снова будет отвечать только поиском.

### Вариант: Claude вместо локальной нейросети

Если у тебя есть ключ Anthropic API, можно отвечать через Claude (умнее, видит свежие данные через веб-поиск,
но платно и через интернет): в `config.json` поставь `"enable_ai": true` и впиши ключ в `"anthropic_api_key"`.

## Автозапуск вместе с Windows

1. Нажми **Win + R**, введи `shell:startup`, нажми Enter — откроется папка автозагрузки.
2. Открой папку Капри и перетащи `run.bat` в папку автозагрузки, **удерживая Alt** (создастся ярлык).

Убрать автозапуск — удали ярлык из этой папки.

## Настройка (`config.json`)

Файл появляется после первого запуска. Открыть: меню в трее → «Открыть config.json».
После изменений перезапусти Капри.

| Параметр | Что меняет |
|---|---|
| `wake_words` | слова, на которые Капри откликается |
| `mic_device` | микрофон (удобнее выбрать в меню трея → «Микрофон»); `null` — как в Windows по умолчанию |
| `sites` | свои сайты: `"название": "https://адрес"` |
| `apps`, `app_aliases` | свои программы и их русские названия |
| `local_ai`, `local_model` | разговор через Ollama и какая модель |
| `enable_ai`, `anthropic_api_key` | разговор через Claude |
| `voice`, `voice_pitch`, `voice_rate` | голос, высота и скорость речи |
| `voice_fx` | цифровая обработка голоса: `0` — чистый голос, `1` — полный эффект |
| `use_google_stt` | точнее распознавать фразы через Google (нужен интернет) |
| `barge_in` | можно ли перебивать Капри голосом (`false`, если она перебивает сама себя из колонок) |
| `chatter`, `chatter_min_minutes`, `chatter_max_minutes` | появляется ли сама и как часто |
| `roam_chance` | как часто при этом гуляет по экрану (`0`…`1`) |
| `teleport_on_answer` | скакать молнией по экрану во время ответа |
| `hide_after_seconds` | через сколько секунд тишины исчезает |

## Внешний вид

- **Позы** — картинки в `assets/poses` (PNG/WebP с прозрачным фоном). Капри меняет их каждые 12–30 секунд.
  `capri_roam.png` — поза для прогулок.
- **Анимации** — кадры в `assets/anim/capri` (машет рукой, при запуске и по команде «помаши»)
  и `assets/anim/eyes` (пока думает). Свои можно сделать из видео:
  ```
  python tools/convert_anim.py "видео.mp4" capri white
  ```
  Последнее слово — цвет фона в видео: `white`, `black` или `green`.

## Голос Капри офлайн (необязательно)

По умолчанию голос — синтезатор Microsoft (нужен интернет). Можно включить офлайн-голос **Silero**:
```
pip install torch --index-url https://download.pytorch.org/whl/cpu
```
и в `config.json`: `"tts_engine": "silero"`, `"silero_voice": "kseniya"` (или `xenia`, `baya`).
Модель (~40 МБ) скачается сама при первом запуске. Лицензия Silero — только для некоммерческого использования.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Капри не слышит | выбери микрофон в меню трея → «Микрофон»; проверь доступ к микрофону в настройках конфиденциальности Windows. В `capri.log` видно, какой микрофон открыт |
| «Не найдена модель распознавания речи» | запусти `setup.bat` ещё раз |
| Отвечает только поиском в Google | установи Ollama и модель (раздел про нейросеть), проверь, что Ollama запущена |
| Перебивает сама себя | надень наушники или поставь `"barge_in": false` |
| Яркость не меняется | работает только на ноутбуках и мониторах с поддержкой DDC/CI |
| Не открывает программу | добавь её в `config.json` → `apps` (`"название": "путь\\к\\программе.exe"`) |
| Не находит чат в Telegram | нужен Telegram Desktop; называй чат так, как он подписан в списке |
| Пишет «Не смогла переключиться на окно» | кликни по нужному окну и повтори — Windows иногда не даёт программам менять активное окно |
| `setup.bat` пишет, что не найден Python | переустанови Python с галочкой «Add python.exe to PATH» |
| Что-то сломалось | подробности — в файле `capri.log` рядом с программой |

## Приватность

- Распознавание речи — офлайн (Vosk). Если включён `use_google_stt`, фраза после имени отправляется в Google для точности.
- Голос Капри синтезируется сервисом Microsoft (отправляется только текст её ответа).
- Разговоры с Ollama не покидают компьютер.
- Отчёты диагностики и журнал хранятся только локально.
